# Test run 2026-11-21: production (celpippracticetest.com), guest

- **Environment:** production, read-only. Fixes were tested locally and pushed to `develop` (not yet on production).
- **Browsers/sizes:** Chromium (desktop app browser pane) at 1366×850 and 375×812.
- **User types:** guest only. Free / paid / admin / mobile-app cases need test accounts and a staging deployment (see "Not run").
- **Tester:** Claude (AI), on request of the site owner.

2. Test accounts: one free, one paid (each plan if possible), one admin.
3. Stripe test-mode keys on that deployment.
